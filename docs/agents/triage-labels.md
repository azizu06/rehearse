# Triage labels

| Role | GitHub label |
|---|---|
| Maintainer evaluation required | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Fully specified and agent-ready | `ready-for-agent` |
| Requires human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

Exactly one triage-state label should normally be active. Removing `needs-triage` requires a reproducible problem or acceptance-tested feature outcome, explicit dependencies, and enough context for the next owner.
