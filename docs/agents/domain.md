# Domain documentation

Rehearse uses a single-context documentation layout.

- Read root `CONTEXT.md` for vocabulary, invariants, and scope boundaries.
- Read root `PRD.md` for product outcomes and release gates.
- Read `docs/adr/` before changing architecture or reversing a decision.
- Add an ADR when a change affects security boundaries, persistence, adapter contracts, sandbox execution, distribution, or a closed scope decision.
- Update `CONTEXT.md` when a domain term or invariant changes. Do not use it as a changelog.
