# v0.1 to v1 roadmap

## Phase 1: vertical foundation

Establish a tested Go/React repository and prove one disposable drill across the API, orchestrator, Docker boundary, UI, report, and cleanup.

## Phase 2: trustworthy v0.1

Add real restic acquisition, PostgreSQL restore, probes, scheduling, metrics, the queued-orders reference workload, packaging, and public documentation.

## Phase 3: adapter breadth and hardening

Add the v1 source/target matrix, crash reconciliation, CI outputs, notification, secret/resource hardening, and migration compatibility hardening.

## Phase 4: infrastructure and release proof

Provision the AWS/S3 demonstration path with Terraform, complete external onboarding, record the demo, run security/accessibility/completion audits, and publish v1.0.

The live GitHub Project and issues are authoritative for dependency order and status.
