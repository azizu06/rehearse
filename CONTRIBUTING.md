# Contributing

Rehearse is pre-v1 and welcomes focused issues, recovery-tool experience reports, documentation improvements, and tested adapter contributions.

Before coding, open or claim a GitHub Issue and confirm that its blockers are closed. Keep one issue per pull request, add tests first when behavior changes, and follow `AGENTS.md` plus `docs/agents/review-policy.md`.

Never include real backup credentials, restored private data, or production connection strings in issues, fixtures, logs, or pull requests.
